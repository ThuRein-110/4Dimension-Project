# SWOT

| Strengths | Weaknesses |
| --- | --- |
| Existing hardware; offline LAN video; no native app; modular TypeScript | Approximate calibration; certificate onboarding; marker dependence; no depth occlusion |

| Opportunities | Threats |
| --- | --- |
| Multi-use student rooms; accessible 4D demonstrations; reusable camera pipeline | Browser permission changes; Wi-Fi isolation; lighting sensitivity; overstated accuracy |

Mitigation: preserve the camera transport, test physical Safari, retain manual
correction, document uncertainty and keep runtime assets local.
