# Stakeholders

| Stakeholder | Interest | Validation |
| --- | --- | --- |
| Student developer | Reproducible Windows workflow and modular code | Install, checks, startup |
| University supervisor | Clear scope, original 4D concept, evidence | Requirements, diagrams, demo |
| Room-planning user | Easy calibration and reversible edits | Task-based usability sessions |
| Camera operator | Clear permissions and privacy | Safari consent, stop behavior |
| Maintainer | Versioned formats and testable boundaries | Automated checks, documented limitations |

The project owner approves scope and supplies the physical iPhone/LAN test.
The application never sends camera footage to university staff or other users.
