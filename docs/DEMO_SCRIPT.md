# Final Demonstration Script

## Preparation

Mount a Windows webcam in a fixed position. No iPhone, Wi-Fi pairing, trusted CA
installation or printed marker is needed for the primary demonstration.
Complete the webcam section of PHYSICAL_ACCEPTANCE.md before claiming hardware success.
Have a tape measure and exported project JSON ready. Demo is an offline fallback,
clearly an illustrative sample rather than live physical-room evidence.

## Live Room Workflow

1. Start Windows app. Explain X/Y/Z space and T state/time.
2. Start webcam, allow permission and show actual moving webcam frames/FPS/resolution.
3. Keep the webcam fixed; demonstrate Fit/Fill/fullscreen.
4. Select noncollinear floor A/B/C, enter tape-measured A-B and confirm manual reference.
5. Show approximate floor grid and enter room dimensions.
6. Add bed/desk with ghosts; select, position, rotate and resize.
7. Add measurement and compare with tape measure; disclose calibration uncertainty.
8. Rename state Current Bedroom (T0); save project.
9. Duplicate to Study (T1); move the same desk/chair and add shelf.
10. Duplicate to Gaming (T2); remove bed and add sofa/lamp; save.
11. Click T0/T1/T2 to restore complete snapshots.
12. Scrub 0 to 2, showing continuous transforms and appearance/disappearance.
13. Play, pause, next and previous without stopping the live camera.
14. Compare T0/T2 with wipe/split/toggle; choose raw camera as Before too.
15. Export composite/3D PNG and editable project JSON.
16. Move the webcam, press Recalibrate and reselect the same references. States remain.
17. Save, reload Windows page, Open project and verify states/furniture/measurements.
18. Recheck calibration before using a changed physical camera view.

## Offline Fallback

Click Demo for Current Bedroom / Study / Gaming. Show editing, undo/redo,
timeline interpolation, comparison, export and reopen. Do not describe sample
pose as a measured camera calibration or synthetic video as physical iPhone proof.

## Optional Secondary Demo

After the webcam workflow is validated, select iPhone camera, install/trust the
PC CA and scan the pairing QR; or expand Optional marker tracking to demonstrate
its measured reference. Failure of either secondary path must not block the
primary fixed-webcam/manual planner demonstration.
