# Project Scope

## In Scope

Windows browser app, iPhone Safari camera, Windows webcam, local media/sample,
with Windows webcam as the primary development source and Safari as secondary;
trusted LAN WebRTC/HTTPS pairing, transparent Three.js world, manual and fiducial
calibration, nine local primitive furniture models with developer GLB loader
support, placement/transforms/history, approximate measurements and overlap
warnings, atomic JSON projects/backups, layouts, interpolated timeline,
comparison, PNG/project exports, demo, onboarding, tests and documentation.

## Out Of Scope V1

Native iOS app, Mac/Xcode, ARKit, LiDAR, RoomPlan, professional surveying,
automatic reconstruction, AI furniture recognition, full SLAM, cloud rendering,
collaboration, e-commerce and motion-sensor fusion.

## Delivery Boundary

The expanded brief authorizes implemented planning/timeline phases following
the existing-system audit. Features have executable code and automated evidence;
physical webcam/manual-alignment acceptance remains pending. iPhone/marker
acceptance is secondary and must not gate the primary webcam planner workflow.
Bundled models are recognizable primitives, not photorealistic GLBs. GLB loading
is a developer extension, not an arbitrary user-model import feature.
